# Subweb

Subweb 是一个独立维护的、单页订阅转换前端。它提供清晰的输入、目标客户端选择与结果复制流程，并把转换请求交给部署者指定的兼容后端处理。

## 项目边界

- 这是纯前端项目，不包含订阅转换后端、节点服务或账号管理功能。
- 默认转换后端为 `https://api.ml1.one`；部署者可通过运行时配置替换为自己的兼容后端。
- 默认短链服务为 `https://ml1.one`。生成短链时，转换链接会发送给短链服务；Base64 编码不是加密。
- “后端默认配置”不会追加 `config` 参数；页面也提供经过来源说明的公开远程配置预设，只有用户主动选择后才会使用对应规则。

## 功能

- 在一个页面内完成订阅链接或节点输入、客户端选择与转换链接生成。
- 支持可展开的高级转换参数、复制和系统原生分享。
- 默认短链服务，并支持通过运行时配置覆盖或关闭。
- 后端默认配置与可选公开远程配置预设。

## 本地开发

推荐使用 Node.js 20 LTS。

```bash
npm ci
npm run serve
```

默认开发服务器会由 Vite 输出本地访问地址。质量检查与生产构建：

```bash
npm test
npm run lint
npm run build
```

构建产物位于 `dist/`，不会被提交到 Git。
