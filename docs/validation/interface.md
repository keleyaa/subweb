# Luminous Focus 界面验证

验证日期：2026-08-02。

真实 Chromium 测试覆盖桌面 `1440 × 900` 与移动 `390 × 844`，每个视口分别运行浅色和深色主题。测试同时覆盖主题持久化、转换与自动复制、剪贴板拒绝后的手动复制反馈、短链 multipart 请求、输入变化后旧结果失效、键盘展开/收起、`44 px` 交互目标、光学居中、横向溢出、减少动态效果、减少透明度和增强对比度。

人工检查使用桌面浅色、桌面深色和移动浅色截图完成。README 提交一张不含订阅值的桌面浅色预览，其他检查图不进入发行内容。浅色与深色均保持单一的主玻璃工作区，大号品牌、工作区和页脚共享同一光学轴；移动端无横向滚动，主题按钮不遮挡字标，服务设置和高级参数默认收起。静态线性环境光只存在于页面背景，不使用循环动画，也不在工作区中嵌套玻璃卡。
