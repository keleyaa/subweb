# Command Interface 界面验证

当前界面验证覆盖固定黑色命令面，不再验证用户可见的浅/深主题切换。

## 浏览器覆盖

真实 Chromium 测试覆盖桌面 `1440 × 900` 与移动 `390 × 844`。当前基线包含 `36` 项浏览器测试，覆盖以下行为：

- 固定黑色命令主题、命令卡中心轴和无横向溢出；
- 订阅输入、客户端与远程配置、生成与自动复制；
- 剪贴板拒绝后的手动复制反馈；
- 短链 multipart 请求与输入变化后的旧结果失效；
- 「订阅后端」和「高级参数」的键盘展开、`aria-expanded`、原位 DOM 位置与互斥收起；
- 高级参数的草稿、保存、重置与状态摘要；
- `44 px` 交互目标、键盘焦点、减少动效与增强对比度；
- 禁用渐变、透明滤镜和 `transition: all`。

运行：

```sh
npm run test:e2e
```

## 人工检查

发布前应在不含订阅值的页面上检查：

1. 宽屏中，卡片标题、中文操作标题和「转换并复制」是否围绕命令卡中心轴；
2. 展开「订阅后端」时，后端面板是否紧跟在该状态行下，而不是落到「高级参数」之后；
3. 切换到「高级参数」时，后端面板是否先收起，且任一时刻只显示一个设置面板；
4. 移动端是否保持单列、无横向滚动，展开内容是否位于所属状态行下；
5. 结果、短链、保存、重置和复制按钮是否都有一致的 hover、按下、焦点与禁用反馈；
6. 页面是否没有用户可见的主题切换控件、玻璃材质、渐变、装饰光球或营销式 Hero。
