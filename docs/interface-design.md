# Command Interface 界面规范

## 目标与结构

界面是一个固定黑色的单任务命令面。用户进入页面后只需要完成一条路径：输入订阅、选择目标、按需调整低频设置、生成并复制。

- 顶部使用紧凑品牌与静态显示状态，不提供明暗主题切换。
- 转换命令卡在宽屏居中，卡片标题、中文操作标题与主命令共享中心轴；快捷键提示独立固定在右侧，不破坏标题对称。
- 订阅输入使用命令提示符，客户端与远程配置并列；窄屏退化为单列。
- 「订阅后端」与「高级参数」是状态行，不是泛化的大块按钮。默认显示当前摘要；展开内容原位出现在所属状态行下。
- 两个设置面板互斥：当前面板先完成收起过渡，目标面板再在自己的状态行下展开。
- 「转换并复制」是受控宽度、居中的唯一主命令；结果与短链操作只在成功后出现。

不增加营销 Hero、统计卡片、模板、侧栏、多页面流程或编造的产品能力。

## 色彩与表面

- 页面固定使用黑色命令主题：深黑背景、略亮的命令卡、荧光绿色主强调、暖白正文与低饱和元数据。
- 不提供用户可见的浅色主题或主题持久化控件；运行时主题属性不得产生可见的双主题差异。
- 表面采用细边界和小圆角，不使用玻璃、背景模糊、渐变、浮层卡片或装饰光球。
- 状态行、输入、结果和次级操作使用同一组边界与文字层级，避免与主命令竞争。
- favicon、PWA 图标与页面使用命令链接符号：黑底、荧光命令提示与链路节点。

## 设置行与反馈

- `订阅后端 / 默认后端` 展开后提供默认后端与自定义 API 地址；选定默认后端或保存自定义地址后更新摘要并收起。
- `高级参数 / 未设置` 使用草稿编辑。只有点击保存才应用到转换请求；重置后恢复默认摘要并收起。
- 面板基础样式与 Vue transition 均显式动画化 `max-height`、内边距、不透明度与位移；`out-in` 阶段保证不会同时展开。
- 主/次按钮和状态行均需提供 hover、active、focus-visible、disabled 反馈；触控目标不小于 `44 px`。
- 剪贴板成功后才显示复制成功；失败时保留结果并提示手动复制。
- 输入变化后立即隐藏旧结果，避免误复制。

## 无障碍与响应式

- 状态行使用原生 `button`，具备 `aria-expanded` 与 `aria-controls`；`Enter`、`Space` 均可操作。
- `prefers-reduced-motion` 下移除位移、缩放和面板动画；`prefers-contrast: more` 或显式高对比状态下增强命令卡、控件边界与焦点环。
- 移动端保留 `16 px` 以上安全边距，禁止横向滚动；设置内容在自身行下占满卡片宽度。
- 不用颜色作为唯一状态提示：摘要、展开符号、文本和可访问名称共同表达状态。
