# Luminous Focus 界面规范

## 目标与结构

界面保持单页、单列和单任务聚焦：大号居中 `Subconverter Web.` 字标、右侧主题按钮、一个转换工作区、一个无框来源页脚。页面不增加营销 Hero、统计卡片、模板、侧栏或多页面流程。

默认只展示订阅输入、目标客户端、远程配置和“转换并复制”。服务设置与高级参数分别折叠，互不嵌套；转换成功后才显示结果和短链操作。输入改变后旧结果立即隐藏，避免误复制。

## 材质与主题

- 页面只允许一个主要玻璃工作面，不给导航和页脚再套玻璃卡片。
- 背景使用覆盖整页的静态蓝、紫、青线性环境光，不绘制离散光球；不使用循环动画、漂浮装饰或插画。
- 浅色和深色主题分别调校，不做简单反色。初次跟随系统，手动选择写入本地偏好。
- 输入与结果面使用更高不透明度以保证可读性；圆角克制，组件不嵌套卡片。
- 品牌、工作区和页脚共享 `52rem` 光学轴；移动端退化为单列并保留 `16px` 安全边距。
- `prefers-reduced-transparency` 下关闭模糊并提高表面不透明度。

## 操作与反馈

- 主按钮固定在表单底部，点击后生成并等待剪贴板 Promise；只有复制成功才显示成功状态。
- 剪贴板失败时保留生成结果，并显示“链接已生成，请手动复制”，不制造假成功。
- 短链只在当前转换结果内出现，同样采用生成并复制、失败可手动复制的单按钮流程。
- 点击目标至少 `44px`，键盘焦点清楚；按压使用轻微 `scale(0.97)`，不引发布局位移。
- `prefers-reduced-motion` 下移除位移和缩放；`prefers-contrast: more` 下增强边界、文字和焦点环。
