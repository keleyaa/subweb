# Apple 风格无框极简首页重设计

**状态：** 用户已选择“无框极简”原型并确认移除本机模板功能

## 目标

在不改变后端协议和转换能力的前提下，将首页重设计为简洁、直接、单页完成的转换工具：

- 保持“输入订阅 → 选择配置 → 转换 → 获取结果”的线性操作顺序。
- 使用克制的 Apple 风格排版、系统字体、细分隔线和单一蓝色主操作。
- 不增加侧栏、检查器、步骤页、仪表盘、营销区块或装饰性视觉元素。
- 完整移除本机模板功能，高级参数默认收起。

## 用户已确认的设计决策

1. 采用“无框极简”而不是卡片式、三栏式或分步式布局。
2. 所有转换操作必须在同一个页面完成。
3. 高级参数默认收起，用户需要时再展开。
4. 本机模板功能完整移除，不再显示、保存、应用、删除或清空模板。
5. 已存在的 `subweb.local-conversion-templates` 浏览器数据不主动删除，避免无提示清理用户本地数据。

## 页面结构

页面维持单一纵向工作流，最大内容宽度约为 `860px`：

1. 简洁顶栏
   - 左侧显示站点名称。
   - 右侧保留 GitHub 链接。
   - 不增加额外导航层级、状态栏或悬浮工具栏。
2. 页面标题
   - 标题为“订阅转换”。
   - 使用一句简短说明，不使用宣传性文案或大面积 Hero。
3. 订阅输入
   - 多行输入框保持页面中最主要的视觉面积。
   - 保留多行输入和 `|` 分隔提示。
4. 基础配置
   - 桌面端同一行显示客户端、后端服务和远程配置。
   - 移动端按客户端、后端服务、远程配置顺序纵向排列。
   - 选择自定义后端或自定义远程配置时，在原位置下方显示对应输入框。
5. 高级参数
   - 默认收起，只显示“高级参数”和展开指示。
   - 展开后显示 Include、Exclude、Emoji、UDP、排序节点、关闭证书检查和 Node List。
   - 展开与收起不改变已填写的参数值。
6. 主操作
   - “转换订阅”是页面唯一蓝色主按钮。
   - 桌面端右对齐，移动端占满可用宽度。
7. 结果
   - 使用细分隔线与前面内容分区，不再包裹额外卡片。
   - 保留转换结果、复制、分享、短链结果、复制短链和生成短链。
   - 分享只在转换结果存在时可用；结果状态使用绿色文字，不使用绿色主按钮。

## 视觉系统

- 字体：`-apple-system`、`BlinkMacSystemFont`、`Segoe UI` 系统字体栈。
- 页面：白色或接近白色背景，不使用渐变、插画、装饰性光斑或大面积玻璃效果。
- 文字：主文字使用接近黑色，说明文字使用中性灰。
- 强调色：Apple 风格蓝色仅用于主操作、链接和焦点状态。
- 边界：用 `1px` 中性细线区分区域，避免卡片嵌套。
- 圆角：输入框和按钮不超过 `8px`。
- 阴影：默认不使用；仅允许通知等临时浮层使用轻阴影。
- 字间距固定为 `0`，不使用随视口缩放的字体尺寸。

## 动效与反馈

- 输入、按钮和选择框在按下时立即响应。
- 高级参数与条件输入使用 `150–220ms` 的 ease-out 展开过渡，不使用弹跳效果。
- 转换、复制、分享和短链继续使用现有通知、弹窗和 loading 行为。
- 支持 `prefers-reduced-motion`；透明材质存在时支持 `prefers-reduced-transparency`。

## 本机模板移除范围

移除以下能力：

- `SubTable.vue` 中模板名称、保存、选择、应用、删除和清空界面。
- 模板相关组件状态、生命周期加载和事件方法。
- `src/features/templates/preferences.js` 中的 localStorage 模板序列化、读取和写入逻辑。
- 仅验证模板存储行为的测试。

当前模板模块还承载客户端选项和高级参数默认值。实现时先将仍需保留的 `TARGET_OPTIONS`、`createDefaultMoreConfig` 和必要的参数归一化逻辑迁移到独立的转换偏好模块，再删除模板存储代码，避免把核心转换常量与废弃功能一起移除。

## 必须保持的行为

- 运行时 `window.config` 字段和所有权不变。
- 转换 URL 的参数和编码规则不变。
- 自定义后端 API 与自定义远程配置的校验不变。
- 转换后自动复制行为不变。
- 短链仍先重新生成转换链接，再按现有 `/short` 协议请求。
- 分享继续优先使用 `navigator.share`，不支持时回退复制。
- Dialog、notification 和 loading 的错误与清理语义不变。
- 所有现有客户端选项继续可用。

## 可访问性与响应式

- 保留所有 label/id 关联、fieldset/legend 语义和键盘 Tab 顺序。
- 焦点状态必须清晰可见，颜色不能作为唯一状态表达。
- `390px`、`768px` 和 `1440px` 宽度不得出现横向滚动、文字遮挡或按钮重叠。
- 在 `390 × 844` 且高级参数收起时，“转换订阅”必须位于首个视口内。
- 移动端控件高度至少 `40px`，主操作高度至少 `44px`。

## 非目标

- 不修改后端、Docker 运行时协议、路由或部署配置。
- 不新增账号、云同步、历史记录、收藏、批量任务或新的网络请求。
- 不引入新的 UI 组件库、图标库或动画库。
- 不重做 Dialog、loading、notification 的视觉体系，除非适配页面时出现明确冲突。

## 验收标准

- 页面视觉和交互与已选择的“无框极简”原型一致。
- 页面中不存在本机模板入口或相关操作文案。
- 高级参数首次加载时处于收起状态，展开后功能完整。
- 桌面和移动端均能在单页完成输入、转换、复制、分享与短链操作。
- 生产源码不引用原型目录，原型不进入默认 Vite 构建产物。
- Vitest、ESLint、Vite build、浏览器桌面/移动回归和 `git diff --check` 全部通过。

## 回滚

重设计和模板移除应作为可独立回滚的前端提交。回滚代码不会删除或迁移浏览器中已有的模板 localStorage 数据。
