# Subweb GitHub README 重设计

## 状态与目标

本设计已获维护者确认，仅覆盖仓库 GitHub 首页 README 的内容层、视觉资产与本地预览。目标是在不把项目包装成营销站的前提下，让首次访问者在首屏理解：这是一个将 Subconverter Web、SubConverter-Extended、MyUrls、Redis 和统一网关整合为一体的可自托管订阅转换发行栈。

本轮不推送远端；实现完成后先交付本地预览和 diff，是否提交或推送由维护者另行决定。

## 受众与项目故事

- **受众：** 想自行部署订阅转换、短链与统一网关的技术用户。
- **一句话价值：** 将订阅转换、短链与受控服务边界放进一个可复现的自托管部署。
- **主要证明：** 已有真实单页界面截图、可执行 Docker / 本机源码入口、锁定版本与公开的架构/安全文档。
- **首次成功动作：** 拉取仓库后运行 Docker 镜像部署脚本，或在本机运行 bootstrap/start。
- **视觉主题：** Luminous Focus；克制的蓝紫环境光、轻玻璃面、系统字体、细线和“输入 -> 转换 -> 分享”流程节点。

## 范围

### 包含

- 重写 README.md 为英文优先、中文紧随的双语首页。
- 创建纯 SVG 标题资产和纯 SVG 架构资产，放在 docs/assets/readme/。
- 复用 docs/assets/subconverter-web.png 作为真实界面证明。
- 提供仅本地使用的 README 预览，不新增线上服务、不修改应用界面、不推送。
- 保留且更易扫描地表达 Fork / 上游来源、部署方式、内部服务边界、文档入口、许可证。

### 不包含

- 不修改 Vue 前端、Nginx、Compose、镜像、部署脚本或运行时行为。
- 不生成真人、吉祥物、照片或装饰性 AI 图像。
- 不添加动画 GIF、远程字体、外部图片依赖、营销数据、未经证明的性能/兼容性主张。
- 不翻译完整 docs 树；README 只链接到现有权威文档。

## 信息架构

README 采用“价值 -> 证明 -> 机制 -> 首次使用 -> 细节”的顺序：

1. 纯 SVG 标题：项目名、双语具体价值说明、输入/转换/短链的流程提示。
2. 真实界面截图，紧接标题作为可见的产品证明。
3. 极简双语介绍与四个可验证事实：双域名、统一网关、内部服务不直暴、可锁定重建。
4. 纯 SVG 架构图：Browser -> App/API Domains -> Gateway -> SubConverter/MyUrls/Redis；明确 Token 和 Redis 数据不进入浏览器。
5. Docker 部署优先，本机源码作为开发/验证入口；每条命令只出现一次，英文说明后紧跟中文说明。
6. Fork 与来源、文档导航、安全边界、许可证的紧凑双语模块。

命令、URL、镜像名称、文件路径和链接为共享技术内容，不重复翻译；语义说明采用英文在前、中文紧随的短段落。长文档维持现有中文权威页面，避免两套资料漂移。

## 视觉系统

| 维度 | 决定 |
| --- | --- |
| Palette | #F5F8FF 背景、#101828 前景、#2563EB 主蓝、#8B5CF6 辅助紫、#667085 静音文字 |
| Typography | SVG 使用系统 sans-serif；技术标签可用系统 monospace；正文保持 GitHub 默认 Markdown 排版 |
| Shape | SVG 使用 12-20 单位的克制圆角、1.5 单位细描边、16 单位间距基线 |
| Motif | 仅使用“输入 -> 转换 -> 分享”三个相连节点，轻量复用在标题与架构图 |
| Composition | 标题 SVG 后接大尺寸真实截图；架构图是单独、可读的系统图，不把细节塞进 Hero |

标题资产采用纯 SVG。它可编辑、轻量、在 GitHub 深浅主题下稳定，且项目已经有更可信的真实截图；没有必要以生成图像替代实际产品输出。

## 双语与无障碍规则

- 所有视觉资产保留 title / desc 和有意义的 Markdown alt 文本。
- SVG 不使用 foreignObject、脚本、外部字体、远程图片或关键动画。
- 正文保持可复制、可搜索、可翻译；命令不放进图片。
- 每个英文信息块立即给出等价中文，不混合成难以扫描的逐句夹杂。
- 不以“Apple 官方设计”或任何第三方品牌为背书；只说明现有界面遵循的材质与可访问性原则。

## 本地预览与验收

实现阶段会在本地生成 GitHub 内容宽度的 README 预览，检查：

- 宽屏和窄屏下 SVG 不裁切，关键文字在约 900px 与 360px 宽度仍可读。
- 深浅背景下的标题和架构图有足够对比度。
- 现有截图、SVG 资产、内部文档链接和锚点均可解析。
- README 不含空泛营销语、模板残留、未验证指标或敏感配置。
- 运行 bundled audit_readme.py、项目文档检查和 git diff --check。

本地预览和 diff 是交付门槛。未收到明确授权前，不执行远端 push。

## 风险与约束

- 完整双语会增加首页长度，因此段落必须短，命令/链接/表格共享。
- README 引用的部署细节必须与现有权威文档一致，不能在首页复制可漂移的完整说明。
- README 视觉资产只服务于理解项目，不替代安全、部署或来源说明。
